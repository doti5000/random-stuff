Protect your WordPress site's images and content from unauthorized AI scraping with a self-destructing, secured web badge.

== Description ==

This plugin injects the official No-AI Badge onto your WordPress site. 
The badge visually indicates that your content is protected and should not be used in AI training datasets.
It is powered by an advanced generator script that includes robust security features like Canvas Rendering, CSS Print Protection, DevTools tamper detection, and Domain Whitelisting.

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to Settings > No-AI Badge to configure the badge's position, size, and link.

== Frequently Asked Questions ==

= Does it affect my site performance? =
No, the badge script is loaded asynchronously and is extremely lightweight.

= Can I hide it on mobile? =
Yes, the script automatically hides the badge on screens smaller than 768px to ensure a clean mobile experience.
